# Rekommenderade capabilities

## Rekommenderat att aktivera

### File uploads

Nödvändigt för att användaren ska kunna ladda upp projektzippar, markdownfiler, datafiler, bilder och befintliga spelprojekt.

### Code Interpreter / Data Analysis

Viktigt för att kunna:

- analysera zippar
- skapa och uppdatera zip-paket
- generera markdown/YAML/JSON
- validera projektstruktur
- skapa enklare printunderlag
- göra filstädning
- skapa rapporter

### Image generation

Rekommenderas om GPT:n ska kunna hjälpa till med:

- konceptbilder
- spelbrädesstämning
- kortillustrationer
- ikonidéer
- visuell stil

Ska inte ersätta datadrivna komponentkällor.

### Web browsing

Rekommenderas om GPT:n ska kunna ge aktuella råd om:

- material
- verktyg
- lamineringsfickor
- pappersskärare
- aktuella priser
- printtjänster
- brädspelsreferenser

## Minsta användbara uppsättning

- File uploads
- Code Interpreter / Data Analysis

## Kommentar

GPT:n är främst tänkt som projektcoach och produktionsassistent. Den viktigaste förmågan är därför att kunna läsa, ändra och paketera projektfiler.
